📦 Interactive Product Inventory

Product Management & Analytics Dashboard

About the Project

This JavaScript mini project manages product inventory, categorizes products by price, calculates total inventory value, filters affordable products, and generates reports.

Project Features

  • Add a product using its name and price
  • Classify products as Budget, Standard, or Premium
  • Calculate total inventory value
  • Filter products priced below $200
  • Generate a formatted inventory report
